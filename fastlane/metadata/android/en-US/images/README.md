# Store Images

Place the following image files in this directory before publishing:

| File | Size | Required |
|------|------|----------|
| `icon.png` (in this folder) | 512×512 px | Yes |
| `featureGraphic.png` (in this folder) | 1024×500 px | Yes |
| `phoneScreenshots/01.png` … `08.png` | any, ≥320px wide | Yes (min 2) |

Images must be PNG or JPEG. Screenshots should show the keyboard in use
(e.g. 5-row layout, Korean input, terminal with Ctrl keys).
